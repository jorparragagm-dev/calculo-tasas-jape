CALCULO DE TASAS JAPE — PWA v1

PUBLICAR GRATIS CON GITHUB PAGES
1. En Windows, descomprime este ZIP.
2. En https://github.com crea una cuenta o inicia sesión.
3. Crea un repositorio llamado calculo-tasas-jape.
4. Sube los archivos de esta carpeta a la raíz del repositorio: index.html, styles.css, app.js, manifest.webmanifest, sw.js, icon-192.png e icon-512.png.
5. En Settings > Pages, elige Deploy from a branch, rama main y carpeta /(root). Guarda.
6. Espera a que aparezca la URL publicada. Tendrá formato https://TU-USUARIO.github.io/calculo-tasas-jape/
7. En el iPhone, abre esa URL en Safari.
8. Pulsa Compartir > Añadir a pantalla de inicio > Añadir.
9. Abre la app desde el nuevo icono y déjala cargar una vez con internet para almacenar los archivos para uso sin conexión.

FUNCIONES
Conversión EA/EM/NAMV, cuota, tasa implícita, monto estimado, comparación de tasas, tabla de amortización, historial local, copiar resultados y exportar amortización CSV.

IMPORTANTE
- La URL de GitHub Pages es pública; no incluyas datos personales ni financieros sensibles.
- El historial se guarda localmente y no se sincroniza entre dispositivos.
- Las cuotas son vencidas mensuales y no incluyen seguros, comisiones ni otros cargos.
- La app requiere HTTPS para instalarse como PWA y habilitar uso sin conexión.
